Experiment 7: Cross-Site Scripting (XSS) Testing

Aim

To manually test a web application's input fields for Cross-Site Scripting (XSS) vulnerabilities by injecting sample scripts and observing whether they execute.

Algorithm/ Procedure

.Open the target web application (e.g., DVWA XSS module) in a browser.

2. Identify input fields that reflect or store user input (search box, comment box, name field, etc.). 3. Enter a simple, harmless test payload into the field.

4. Submit the form and observe whether an alert box pops up (this confirms the input was not

sanitized).

5. Repeat with a stored-XSS test in a field that saves data (e.g., a guestbook/comment) to check if the payload executes for other users too.

6. Record which fields are vulnerable (reflected vs stored XSS).

7. Document the fix: proper output encoding/escaping and input validation on the server side.
